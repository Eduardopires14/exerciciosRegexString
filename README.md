# Exercícios de Regex e Strings

Este repositório contém exercícios práticos de **expressões regulares (Regex)** e manipulação de **strings em Java**.  
O objetivo é consolidar conceitos fundamentais de programação relacionados ao tratamento de textos, padrões e validações.

## 📚 Conteúdo

- **Regex (Expressões Regulares):**
  - Criação e uso de padrões para busca em textos.
  - Validação de formatos (e-mails, CEP, CPF, etc.).
  - Substituição e extração de informações.

- **Strings em Java:**
  - Métodos da classe `String`.
  - Manipulação de substrings.
  - Comparação e ordenação.
  - Conversão entre tipos.

## 🛠️ Tecnologias

- Linguagem: **Java**
- IDE sugerida: IntelliJ IDEA
